# Roadmap — Potato Boost

Why this file exists: so someone who opens the project in two years can see **the problem**, **the build order**, and **when the tool is ready**.

Product source: [PRD.md](../PRD.md). GitHub: [iamthamanic/potato-boost](https://github.com/iamthamanic/potato-boost). German original: [ROADMAP.md](../ROADMAP.md).

## Ready means

**MVP (Web/Three.js):** detect, confirm, quick-scan, evidence-backed findings, compare a fix to a baseline, same report in CI — local, offline, no cloud account. Release gate: PRD T-001–T-013.

**Not MVP:** Godot, Tauri, .NET, autonomous patches, SaaS, hardware farm, VisoDev as a dependency.
